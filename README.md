# Chuply Home

Landing page for **chuply.com** — the main brand page linking to all Chuply products:

- [ShopFront SA](https://shopfront.chuply.com) — online store builder
- [Chuply Ops](https://ops.chuply.com) — field service management
- [Chuply Schools](https://schools.chuply.com) — cashless tuckshop payments
- [Chuply Summaries](https://summaries.chuply.com) — academic summaries

Plain static HTML/CSS, no build step.

## Publish

1. In GitHub Desktop: **File → Add Local Repository** → select this `chuply-home` folder → **Publish repository**.
2. In Vercel: **Add New → Project** → import `chuply-home` → Deploy (no framework preset needed, root directory is fine as-is).
3. In Vercel project settings → Domains → add `chuply.com` (and `www.chuply.com` if wanted).
